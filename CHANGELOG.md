# Changelog

## 4.0.0 — 2026-08-25

- Separated source/resources from personal data and downloaded models.
- Added installed and portable storage modes.
- Added frozen-executable startup and model-download handling.
- Centralized application identity and version metadata.
- Organized developer tools and interface reference images.
- Added MIT licensing, privacy documentation, notices, and release scaffolding.
- Added a reusable vector application icon and multi-resolution Windows icon.
- Added the Nimbus cover-video easter egg under its separate media notice.
- Added first-run, opt-out model setup with all local models preselected and
  Medium clearly marked as recommended.
- Built and smoke-tested the self-contained Windows application and installer.
- Removed generated dependencies, local model weights, caches, and personal
  runtime state from the source baseline.

## 3.9.0
